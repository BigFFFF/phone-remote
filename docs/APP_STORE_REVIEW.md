# App Store review notes

Phone Remote is a native Flutter app that controls a user-owned Windows PC on the same LAN. Live
mode requires Windows Companion; an offline Demo mode lets reviewers inspect the interface without
LAN access.

Review notes should mention local-network discovery, the Companion requirement, Demo mode, and the
absence of cloud accounts, analytics, ads, or keyboard-content collection.

Before submission, complete physical iPhone testing, Xcode compilation, signing, screenshots,
privacy disclosures, support/reviewer metadata, and any required network entitlement. Claim an
Apple entitlement only after approval.
