# Web Remote

Web Remote 让普通浏览器通过可信私有局域网控制电脑，无需安装证书。原生 App 仍使用
HTTPS 8765；Web Remote 使用 HTTP 8766。

## 使用

1. 将手机和电脑连接到同一个可信 Wi-Fi，并把 Windows 网络设为“专用网络”。
2. 在托盘菜单选择 “Copy Device Address”。
3. 用手机浏览器打开该地址，例如 `http://192.168.1.20:8766/`。
4. 请求验证码，并输入 Windows 通知中的六位配对码。

Web Remote 拥有独立凭据，可在电脑管理页单独撤销。管理页本身只能从电脑本机访问。

HTTP 流量不加密，局域网中的其他设备可能读取凭据、键盘文本和控制指令。不要在访客
Wi-Fi、酒店、共享网络中使用，也不要配置端口映射、公共防火墙放行或云隧道。
